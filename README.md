# QCU Campus GPS Monitor

## Research Title

A Descriptive Research on the Use of GPS-Based Location Tracking for QCU Buildings, Departments, and Campus Navigation

## Purpose

The system is a research prototype for GPS-based campus location tracking and navigation.

## Main Features

- Student GPS location sharing
- Faculty GPS location sharing
- Staff GPS location sharing
- Guest GPS location sharing
- Administrator live monitoring
- Firebase Authentication
- Firebase Realtime Database
- Live location updates
- Campus building directory
- GPS accuracy display
- Responsive mobile and tablet interface
- Campus navigation prototype

## Technology

- React
- Vite
- Firebase Authentication
- Firebase Realtime Database
- Leaflet
- OpenStreetMap
- Render
- GitHub

## Privacy

Location sharing requires user permission.

The user must explicitly start location sharing.

The system should only collect information necessary for the approved research purpose.

## Deployment

GitHub → Render → Firebase

## Important

The campus coordinates included in the prototype must be verified against official QCU campus/building coordinates before research deployment.
